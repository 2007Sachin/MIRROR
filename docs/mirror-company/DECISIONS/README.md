# Decision records

One file per significant decision: `DR-NNNN-<slug>.md`. Do not reopen a settled record without new evidence or its revisit condition.

## Template

```
# DR-NNNN <title>
Status: Proposed | Accepted | Superseded by DR-XXXX | Rejected
Date · Owner
## Problem
## Evidence            (cite files / measured results)
## Options considered  (include "do nothing")
## Arguments           (for/against, who raised them)
## Decision
## Reason
## Consequences
## Revisit when
```
